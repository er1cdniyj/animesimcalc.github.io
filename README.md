# Anime Simulator Calculators

Calculators and tools for **Anime Simulator** to help players with stats, coins, goals, trading, and more.

---

## 🚀 Features
- **Stats Gain Calculator** – estimate training gains
- **Coin Calculator** – calculate coin earnings by rank and bonuses
- **Goal Calculator** – find time needed to reach target stats
- **Trading Calculator** – compare companion trade values
- **Companion & Aura Values** – quick reference for trading
- **Guides Section** – tips, strategies, and community resources
